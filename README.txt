NEXUS HACK — نسخة أولية قابلة للتشغيل

التشغيل:
1) فك ضغط الملف.
2) افتح index.html باستخدام Chrome أو أي متصفح حديث.
3) اختر مختبراً وابدأ التدريب.

ملاحظات:
- هذه نسخة واجهة أمامية تجريبية (HTML/CSS/JavaScript).
- تقدم المتدرب والنقاط تحفظ محلياً في المتصفح عبر localStorage.
- لا يوجد حتى الآن تسجيل دخول حقيقي أو قاعدة بيانات مشتركة أو لوحة مدير أو رابط عام.
- لا تستخدم بيانات حقيقية. كل السيناريوهات تدريبية ومحاكاة.
- للنشر كرابط عام: ارفع مجلد المشروع إلى خدمة استضافة صفحات ثابتة تدعم HTML، بعد إنشاء حسابك بنفسك.
